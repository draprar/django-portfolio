# Audio retention

Ćwiczba does not upload a recording and does not transcribe one.

The speaking page can record in the browser so the learner can listen back. That file stays on the device. The score uses the text the learner types (`writing_eval_v2`). Speech-to-text stays out until there is a written decision about where a file would be stored, how long it would be kept, who could open it, and how the learner would delete it.
